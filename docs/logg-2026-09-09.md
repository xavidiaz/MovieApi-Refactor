## Flödesbeskrivning – var är vi nu

Actor-kedjan komplett hela vägen:

```
GET /actors
  → ActorsController (IActorService)
  → ActorService (IUnitOfWork)
  → ActorRepository.GetAllAsync()  →  context.Actors.ToListAsync()
  → SQLite: movies.db
```

Review-kedjan finns från repository ner till databasen, men ingen väg ut till
API:et ännu (`ReviewService` ofärdig, ingen `ReviewsController`).

Databasens relationer:

```
Movies ──< Reviews        one-to-many  (FK Reviews.MovieId, cascade)
Movies >──< Actors         many-to-many (join-tabell ActorMovie)
```

## Kända, avsiktliga begränsningar

- `GET /movies` och `GET /actors` returnerar inte varandras relationer
  (`"reviews": []`, `"actors": []`) – repositories gör platt `ToListAsync()`
  utan `.Include`. Medvetet naivt; löses av DTOs i **Fas 8**. Att lägga
  `.Include` nu skulle dessutom trigga referenscykler i JSON-serialiseringen.
